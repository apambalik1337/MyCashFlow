# 💸 MyCashFlow

> A simple and modern personal finance tracker to help you manage your income, expenses, budgets, and savings goals.

MyCashFlow is a lightweight **personal cash flow management web application** designed to help users understand their spending habits and take better control of their finances.

## ✨ Features

* 📊 Financial Dashboard
* 💵 Income Tracking
* 🛒 Expense Management
* 👝 Multiple Wallets
* 📈 Spending Analytics
* 📅 Financial Calendar
* 🎯 Budget Planning
* 🏆 Savings Goals
* 🔁 Recurring Transactions
* 🧾 Transaction History
* 🌙 Modern Dark Interface

## 💰 Currency

MyCashFlow is configured to use **Malaysian Ringgit (RM)**.

## 🚀 Getting Started

No installation is required.

Simply download or clone the repository and open:

```text
index.html
```

in your web browser.

Alternatively:

```bash
git clone YOUR_REPOSITORY_URL
cd MYCASHFLOW
```

Then open `index.html`.

## 🔒 Privacy

Your financial data is stored locally in your browser. No external server or cloud database is required.
